# AI-Resume-Analyzer-
 A full-stack web application that uses Machine Learning techniques to analyze resumes and provide an intelligent score with detailed feedback and improvement suggestions to help users optimize their CVs for better job opportunities.
Features
📄 Upload and parse resumes (PDF/DOC support)
🧠 Machine Learning-based resume analysis and scoring system (0–100)
📊 Smart categorization:
Excellent (80–100)
Good (60–79)
Average (40–59)
Weak (<40)
🔍 Skill extraction using NLP/ML techniques
📝 Personalized resume improvement suggestions
🤖 Integrated AI Chatbot for resume-related guidance and doubt solving
⚡ Fast and scalable backend processing
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB (Atlas)
Machine Learning: NLP model / ML-based scoring logic integrated via API
File Handling: Multer
AI Chatbot: NLP  OpenAI API 
Other Tools: dotenv
🎯 How It Works
User uploads a resume
Backend extracts text from the file
ML/NLP model analyzes:
Skills
Keywords
Resume structure
A smart score (0–100) is generated
System provides:
Feedback
Improvement suggestions
AI chatbot helps users with resume-related queries in real time
