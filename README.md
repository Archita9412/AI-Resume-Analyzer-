AI Resume Analyzer

A full-stack web application powered by Machine Learning (NLP) that analyzes resumes and provides an intelligent score with detailed feedback and improvement suggestions to help users optimize their CVs for better job opportunities.

🚀 Features
📄 Upload and parse resumes (PDF / DOC support)
🧠 ML-based resume analysis and scoring system (0–100)
📊 Smart scoring categories:
🟢 Excellent (80–100)
🔵 Good (60–79)
🟡 Average (40–59)
🔴 Weak (<40)
🔍 Skill extraction using NLP techniques
📝 Personalized resume improvement suggestions
🤖 AI-powered chatbot for resume guidance and doubt solving
⚡ Fast and scalable backend processing
🛠️ Tech Stack

Frontend:
HTML, CSS, JavaScript

Backend:
Node.js, Express.js

Database:
MongoDB (Atlas)

Machine Learning / AI:
NLP model / ML-based scoring logic (API integrated)

File Handling:
Multer

AI Chatbot:
OpenAI API / NLP-based chatbot

Environment Management:
dotenv

🎯 How It Works
User uploads a resume (PDF / DOC)
Backend extracts text from the file
NLP/ML model analyzes:
Skills
Keywords
Resume structure
System generates a smart score (0–100)
User receives:
Detailed feedback
Improvement suggestions
AI chatbot provides real-time resume assistance
